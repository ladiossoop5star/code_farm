# 第 19 集｜從 FAIL 到 PASS 的修復迴圈

這個本機 C 練習保留了網路驅動回收 TX 描述符時最重要的環狀索引關係。測試程式直接提供裝置的完成指標，適用於觀察回收邏輯和 AI 操作流程。

## 重跑

需要 Bash、C 編譯器、Make 和 Python 3.11 以上。這裡沿用第 17 集的最小版 Edward。

1. 將此教材放進新的練習目錄，執行 `make`，保留由起始程式編出的 `tx-check`。
2. 在同一目錄開啟你的 coding agent，把 [任務提示詞](prompt.zh-TW.md) 完整交給它。Agent 會先跑 `./edward tx-wrap.toml`，讀這輪的結果，再找原因。
3. 看它改了什麼、執行了哪次 `make`，以及重新執行相同測試時的原始輸出。[英文提示詞](prompt.en.md)

初測的 `wrap` 回收清單是空的，待完成筆數仍是 4。回測時這列應依序回收 201、202、203，留下 1 筆待完成。另 2 列 `linear` 和 `idle` 也要符合 [TOML 中的判準](tx-wrap.toml)。要親手重跑，使用同一條 Edward 命令就能看到每列結果。終端最後一行會印出暫存 report 的位置，讀完即可刪除。

同一份 TOML 可用於修正前後。要從原版開始另一輪，重新複製教材到新的練習目錄。
